# Learn C++ OOP
A collection of C++ program examples. Each file covers a single topic and includes explanatory comments.

## Structure
Each file is named `NN_topik.cpp` and is self-contained (has its own `main()`). The number in front indicates the learning order, so the file list on GitHub automatically reads in sequential order.

## How to Run
Make sure `g++` is installed, then compile and run the desired file :

```bash
g++ -Wall nama_file.cpp -o nama_file
./nama_file
```

Example :

```bash
g++ -Wall 01_pointer.cpp -o 01_pointer
./01_pointer
```


## Environment

- Ubuntu 22.04 (WSL)
- Visual Studio Code
- g++
